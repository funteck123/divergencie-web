**World & Country Toppers. Prestige. Results.**

**1. Brand Overview**

DivergenCIE Coaching is a premium online coaching institution led by Cambridge A Level Country and World Toppers, examiners, and experienced teachers. Students are accepted at top UK universities including the University of Edinburgh, London School of Economics (LSE), and Imperial College London.

This document defines the visual and verbal identity of DivergenCIE. All team members, designers, content creators, and external partners must adhere to these guidelines to maintain brand consistency across every touchpoint.

**1.1 Mission Statement**

To deliver world-class, personalised Cambridge curriculum coaching that empowers students globally to achieve A\* grades, gain admission to prestigious universities, and develop the academic rigour needed for lifelong success.

**1.2 Brand Personality**

|                |                                                                          |
| -------------- | ------------------------------------------------------------------------ |
| **Attribute**  | **Description**                                                          |
| Premium        | High standards — every interaction feels exclusive and professional      |
| Expert         | Led by toppers and examiners; authority and credibility in every message |
| Warm           | Teachers who genuinely care; approachable, supportive, never cold        |
| Global         | Students and staff from UK, India, Malaysia, KSA, Pakistan and beyond    |
| Results-Driven | A\* is not aspirational — it is the expected outcome                     |

**1.3 Taglines & Voice**

  - Primary: "Ace your exams with flying colours and get the A\*"

  - Secondary: "World & Country Toppers. Prestige. Results."

  - Tone: Confident, warm, academic, never boastful

  - Avoid: Vague promises, overly casual slang, excessive exclamation marks

**2. Colour Palette**

**2.1 Colour Usage Rules**

  - Never place Brand Gold text on white — use navy background for gold text

  - Never use pure black (\#000000) for body text — use \#1A1A1A

  - Primary CTA buttons: Gold (\#E8A832) background with white text

  - Secondary CTA buttons: Navy (\#1A3C5E) background with white text

  - Links: Sky Blue (\#4A9FD4), underline on hover

  - Error states / alerts: Coral (\#E05A4E)

  - Dark backgrounds / footers: Charcoal (\#5C5248) or Navy (\#1A3C5E)

**3. Typography**

**3.1 Font Stack**

|                        |                                                                 |
| ---------------------- | --------------------------------------------------------------- |
| **Usage**              | **Font**                                                        |
| Primary (headings, UI) | Inter — Google Fonts (free, modern, highly legible)             |
| Secondary (body text)  | Merriweather — Google Fonts (academic, readable at small sizes) |
| Monospace (code, data) | JetBrains Mono or Courier New                                   |
| Document fallback      | Arial, Helvetica, sans-serif                                    |
| Print / DOCX           | Arial only (universal support)                                  |

**3.2 Type Scale**

|                        |                                       |
| ---------------------- | ------------------------------------- |
| **Element**            | **Size / Style**                      |
| Page Title / Hero      | 48–60px, Bold, Navy                   |
| H1 — Section Heading   | 36px, Bold, Navy                      |
| H2 — Sub-section       | 28px, SemiBold, Navy                  |
| H3 — Component heading | 22px, SemiBold, Dark                  |
| Body Text              | 16–18px, Regular, \#1A1A1A            |
| Captions / Labels      | 13–14px, Regular, \#666666            |
| Buttons / CTAs         | 16px, SemiBold, White on Navy or Gold |
| Footer text            | 13px, Regular, \#888888               |

**3.3 Typography Rules**

  - Never mix more than two typefaces on a single page

  - Line height: 1.6 for body, 1.2 for headings

  - Letter spacing: 0 for body; -0.02em for large headings

  - Never justify body text — use left alignment

  - Bold sparingly — only for the single most important word or phrase per paragraph

**4. Logo Usage**

**4.1 Logo Description**

The DivergenCIE logo consists of two elements: (1) an icon — an open book on a rounded-square charcoal background (\#5C5248) with three coloured bookmark tabs in sky blue, gold/amber, and coral; and (2) a wordmark — 'DivergenCIE' in bold serif, where the full word reads as one with 'CIE' visually prominent to reference Cambridge International Education. Above the logo, Cambridge Assessment International Education and CollegeBoard affiliations are displayed.

**4.2 Logo Versions**

|                             |                                                 |
| --------------------------- | ----------------------------------------------- |
| **Version**                 | **Usage**                                       |
| Full Logo (wordmark + icon) | Website header, letterheads, official documents |
| Icon only                   | Favicon, app icon, social media profile picture |
| White version               | Dark/navy backgrounds                           |
| Navy version                | Light/white backgrounds                         |
| Gold version                | Special awards, certificates, premium materials |

**4.3 Clear Space & Sizing**

  - Minimum clear space: equal to the height of the 'D' in DivergenCIE on all sides

  - Minimum digital size: 120px wide

  - Minimum print size: 30mm wide

  - Never stretch, rotate, recolour, add drop shadows, or place on busy backgrounds

  - Never use low-resolution versions — always use SVG or high-res PNG

**5. Imagery & Visual Style**

**5.1 Photography Guidelines**

  - Use: Diverse students at desks, studying, or celebrating results; real teacher-student interaction

  - Avoid: Generic stock images of empty classrooms, non-Cambridge exam papers, or overly posed photos

  - Preferred style: Bright, natural lighting; authentic moments; slight cool tone to align with navy palette

  - Student photos: Always obtain written consent before publishing

**5.2 Icons & Illustrations**

  - Icon style: Outline/line icons, 2px stroke, rounded corners — consistent with Inter font's geometric feel

  - Recommended library: Lucide Icons, Phosphor Icons, or custom SVG

  - Illustration style: Minimal flat design with navy, gold, and white — no clipart or cartoons

**6. Tone of Voice**

**6.1 Writing Principles**

  - Be direct and confident — state facts, not hopes ("Our teachers are Cambridge Toppers" not "We try to hire top teachers")

  - Be warm but professional — avoid corporate coldness and avoid slang

  - Use active voice — "We deliver results" not "Results are delivered"

  - Keep sentences short — maximum 25 words per sentence in marketing copy

  - Always capitalise: A\*, IGCSE, A Level, Cambridge, DivergenCIE

**6.2 Example Copy**

**8. Brand Do's and Don'ts**

|                                                      |                                                      |
| ---------------------------------------------------- | ---------------------------------------------------- |
| **Do**                                               | **Don't**                                            |
| Use the exact brand colours                          | Create new colours or tints not in this palette      |
| Use Inter and Merriweather on web                    | Mix more than two fonts on any page                  |
| Write 'A\*' in all communications                    | Write 'A star' or 'A-star'                           |
| Capitalise 'DivergenCIE' exactly as shown            | Write 'Divergencie', 'DIVERGENCIE', or 'divergenCIE' |
| Use high-resolution logo files                       | Stretch, rotate, or recolour the logo                |
| Get written consent before publishing student photos | Share student results without permission             |
| Always lead with results and credentials             | Make vague promises without evidence                 |
