# Commit format and release workflow

Follow `CONTRIBUTING.md` for every commit: Conventional Commits format
(`feat`/`fix`/`docs`/`chore`/`refactor`/`perf`), update `CHANGELOG.md`'s
`[Unreleased]` section in the same commit, and never push to `origin`
without asking first — it auto-deploys straight to production.
