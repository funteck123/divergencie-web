## SIGNATURE

export function expandRecurrence(
  rule: RecurrenceRule,

## INPUT TYPES (define these in the module's contracts/ — do not import prisma)
These are a hand-written projection of the `ScheduleOccurrence` fields relevant to
recurrence (schema lines 705–725). The build chat defines them; it must NOT depend on
the generated Prisma client.

```ts
export type RecurrenceType =
  | "WEEKLY" | "BIWEEKLY" | "MONTHLY" | "YEARLY" | "ONE_OFF" | "CUSTOM";

export type Weekday =
  | "MONDAY" | "TUESDAY" | "WEDNESDAY" | "THURSDAY"
  | "FRIDAY" | "SATURDAY" | "SUNDAY";

export interface RecurrenceRule {
  recurrenceType: RecurrenceType;
  dayOfWeek: Weekday | null;   // WEEKLY/BIWEEKLY
  dayOfMonth: number | null;   // MONTHLY (1–31); YEARLY (day component)
  monthOfYear: string | null;  // YEARLY — month name or 1–12 as string
  oneOffDate: Date | null;     // ONE_OFF
  customPattern: string | null;// CUSTOM, e.g. "every 5 days" | "3x per month"
  startTime: Date;             // carries the TIME-OF-DAY applied to each occurrence
  anchorDate: Date;            // the activatedAt / schedule start — BIWEEKLY phase + CUSTOM origin
}

export interface DateRange {
  from: Date;  // inclusive
  to: Date;    // exclusive
}
```

## OUTPUT TYPE
`Date[]` — every occurrence datetime that falls within `[window.from, window.to)`,
ascending, each carrying the time-of-day from `rule.startTime`. UTC throughout.

## RULES (each cites the handoff; §10 = system-logic-handoff-v23.md lines 507–564)
1. **WEEKLY** (§10): one occurrence every 7 days on `dayOfWeek`, within the window.
2. **BIWEEKLY** (§10): every 14 days on `dayOfWeek`. Phase is anchored to `anchorDate`
   — only weeks whose offset from the anchor week is even are emitted.
3. **MONTHLY** (§10): one per calendar month on `dayOfMonth`. If `dayOfMonth` exceeds
   the month length (e.g. 31 in Feb), **skip that month** (do not clamp to the 28th).
4. **YEARLY** (§10): one per year on `monthOfYear` + `dayOfMonth`. Accept `monthOfYear`
   as either a month name ("January") or a numeric string ("1"–"12"), case-insensitive.
5. **ONE_OFF** (§10): return `[oneOffDate]` iff it lies within the window, else `[]`.
6. **CUSTOM** (§10): parse `customPattern`. Support exactly two grammars for now:
   - `"every N days"` → every N days from `anchorDate`.
   - `"Nx per month"` → N evenly-spaced days within each month (floor-spaced from day 1).
   Any unrecognised pattern → return `[]` (do NOT throw).
7. **Time-of-day:** every emitted Date takes hours/minutes/seconds from `rule.startTime`.
8. **Window boundary:** `from` inclusive, `to` exclusive.
9. **Ordering:** ascending. **Determinism:** same inputs → identical output.
10. **No I/O, no now():** never read the system clock. Output depends solely on args.

## DONE WHEN
`src/modules/scheduling/core/__tests__/expandRecurrence.test.ts` is green and covers:
- WEEKLY: window spanning 3 weeks → 3 dates on correct weekday.
- WEEKLY: dayOfWeek before window start in first partial week is excluded.
- BIWEEKLY: correct alternating weeks vs anchorDate (emit even-offset weeks only).
- MONTHLY: dayOfMonth=15 over 3 months → 3 dates.
- MONTHLY: dayOfMonth=31 in a window including February → February skipped (rule 3).
- YEARLY: monthOfYear name vs numeric string both resolve to same date.
- ONE_OFF inside window → 1 date; outside → empty.
- CUSTOM "every 5 days" from anchor → correct spacing.
- CUSTOM "3x per month" → 3 evenly-spaced dates that month.
- CUSTOM unrecognised pattern → empty array (no throw).
- Time-of-day from startTime applied to every result.
- Boundary: occurrence exactly at `from` included; exactly at `to` excluded.
- Empty window (`from >= to`) → empty array.
- Determinism: two calls with identical args deep-equal.
