## [Unreleased]

### Features

* **accounts:** Management can "Log in as" a Student/Teacher/Staff/Parent/Ambassador account without ever seeing or resetting their password, via a short-lived impersonation session with a visible "Stop impersonating" banner and full audit logging. Replaces a proposed change to make stored passwords reversible/viewable again, which would have reopened the plaintext-password-leak incident scrypt hashing was introduced to fix.

* **mcq-digitizer:** Mathematics (and any other subject with no real MCQ paper) can now be practiced question by question in the Question Solver, using the exact same practice-mode UI as the MCQ flow -- a mode-select card, then one card per question with a Question/Answer tab toggle revealing that question's own real mark-scheme crop, no separate stepper or "Open Question Paper" screen.

* **mcq-digitizer (TKT-0242):** structured papers (Theory, Practical, Mathematics -- any non-MCQ component) now have a real Test mode, enabled and exposed to students for the first time -- same "Answer the quiz" flow as MCQ, but the A/B/C/D options are replaced by one combined text box per question for the student's full working. Each question is submitted (and graded) individually rather than all at once at the end -- silently, no score shown until the results screen, same as MCQ never reveals anything mid-quiz either -- and can still be edited and resubmitted afterward; the final "Submit quiz" only has to grade whatever wasn't already submitted (or was edited since). Submitting sends each question's own mark-scheme crop image (never its extracted text) plus the student's answer to Gemini (OpenRouter as fallback) for grading. A question only counts as correct toward the score if it earned FULL marks. The flow itself was already built but had been sitting behind a disabled "coming soon" button, and never recorded a single attempt or mistake even when it did briefly run -- this also wires it into the same progress-tracker/leaderboard/mistake-log tracking MCQ's Test mode already had, none of which existed for structured papers before.

* **mcq-digitizer (TKT-0245):** each worksheet now has "View QP PDF" / "View MS PDF" links -- shown in the paper's mode-select menu and in Practice mode, hidden in Test mode (exam integrity). Clicking streams the real PDF straight from a new same-origin endpoint (`GET /api/mcq/pdf`, proxying `server.mjs`'s existing `downloadDriveFile`) as a forced download, rather than sending the student to a Google Drive view page they may not even have access to.

* **mcq-digitizer (TKT-0246):** Mistakes Mode moved from a generic account-wide link on the home screen into a button next to the Component selector in the main picker, and is now scoped to only the mistakes belonging to papers in that one selected Component -- previously it pulled every unresolved mistake across every subject the student had ever answered a question in, regardless of what they were currently browsing.

### Bug Fixes

* **resources:** Syllabus Viewer link now carries `?account=&name=` like Question Solver already did, so its own "My progress & leaderboard" feature is actually reachable instead of permanently hidden behind a `display:none` link nobody could unlock.

* **mcq-digitizer:** fixed two per-question splitter bugs found by auditing all 391 Mathematics Paper 2/Paper 4 worksheets for atomicity. (1) Some mark schemes carry a duplicate "Question N" heading at the exact same position as the real one, mislabeled one number too high -- the browser's `find()` silently paired every even-numbered question with a near-blank duplicate crop instead of its real mark scheme. (2) Some multi-page questions repeat their own "Question N" heading on the continuation page, which the splitter mistook for a second question, splitting one question into two. Also fixed a font-encoding variant (`\x03` used as inter-word spacing instead of a real space) that made 4 worksheets fail to split at all. All 391 papers now split atomically, verified by a full-corpus recheck.

* **mcq-digitizer (TKT-0243):** a Test-mode attempt's `totalQuestions` sent to the progress tracker/leaderboard counted every question in the paper that had a real answer key, whether the student actually answered it or not -- opening a 10-question paper and answering only 5 recorded totalQuestions=10, inflating the denominator with questions never attempted. Now counts only the questions actually answered (MCQ) or actually submitted (structured). The on-screen score shown immediately after submitting is unaffected -- this only changes what gets persisted to history/leaderboard.

* **mcq-digitizer (TKT-0244):** the attempt-history table showed a raw Google Drive file id instead of a readable worksheet title whenever a past attempt's subject fell outside the student's current enrollment -- `paperTitleById` was built only from the enrollment-filtered library response. Added `GET /api/mcq/paper-titles`, a title-only lookup deliberately NOT filtered by live enrollment (a past attempt's paper name isn't a "what can this student browse" question), which now backfills any gap in the title map.

* **resources:** Syllabus Viewer's link had gone dead -- its standalone server and Cloudflare tunnel (a separate always-on process this hardcoded URL points at, unlike Question Solver's which is DB-config-driven) were not running at all. Restarted both and updated the hardcoded URL to the new tunnel. Confirmed via Vercel runtime logs this was not a platform/env-var issue -- no env var drives this URL anywhere, the latest deployment was healthy, and the one runtime error in the last 24h was a single transient timing blip during the Question Solver tunnel's own restart, not a recurring fault.
